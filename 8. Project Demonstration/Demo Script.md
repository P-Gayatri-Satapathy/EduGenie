# Demo Script

## Project Title

EduGenie – AI-Powered Personalized Learning Assistant

---

## Introduction

Hello everyone.

My project is **EduGenie – AI-Powered Personalized Learning Assistant**.

EduGenie is developed using **Python, FastAPI, HTML, CSS, JavaScript, Jinja2, and Google Gemini AI**. It helps students by answering educational questions, explaining concepts, generating quizzes, summarizing educational content, and recommending personalized learning paths.

---

## Demonstration

### Step 1 – Open the Application

Run the application using:

```bash
uvicorn main:app --reload
```

Open the browser:

```
http://127.0.0.1:8000
```

---

### Step 2 – Home Page

The home page displays:

- Module Selection
- Input Text Area
- Generate Button
- Result Section

---

### Step 3 – Question Answering

Select:

Question Answering

Example Input:

```
What is Artificial Intelligence?
```

The system generates a detailed educational answer.

---

### Step 4 – Concept Explanation

Select:

Concept Explanation

Example:

```
Photosynthesis
```

EduGenie explains the concept in simple language.

---

### Step 5 – Quiz Generation

Select:

Quiz Generation

Example:

```
Python
```

The system generates three multiple-choice questions.

---

### Step 6 – Text Summarization

Select:

Summarization

Paste a long paragraph.

EduGenie returns a concise summary.

---

### Step 7 – Learning Recommendations

Select:

Learning Recommendations

Example:

```
SQL
```

EduGenie generates a structured learning roadmap from beginner to advanced level with recommended resources.
