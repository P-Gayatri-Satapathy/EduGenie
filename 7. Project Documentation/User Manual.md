# User Manual

## Introduction

EduGenie is an AI-powered educational assistant that helps students learn more effectively through intelligent educational support.

---

## Available Modules

### Question Answering

Allows users to ask educational questions and receive detailed AI-generated answers.

---

### Concept Explanation

Provides simple explanations for difficult concepts.

---

### Quiz Generation

Creates multiple-choice questions for practice and self-assessment.

---

### Text Summarization

Summarizes lengthy educational content into concise points.

---

### Learning Recommendations

Generates a personalized learning roadmap with beginner, intermediate, and advanced resources.

---

## Steps to Use

1. Open EduGenie.
2. Select a module from the dropdown.
3. Enter a question, topic, or paragraph.
4. Click the **Generate** button.
5. View the generated result.
