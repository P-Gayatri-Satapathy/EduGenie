# Frontend Development

## Overview

The EduGenie frontend was developed using HTML5, CSS3, JavaScript, and Jinja2 Templates. It provides a clean and user-friendly interface where users can interact with different educational modules.

---

## Frontend Components

- HTML5
- CSS3
- JavaScript
- Jinja2 Templates

---

## Features

- Dropdown menu for module selection
- Text area for user input
- Generate button
- Dynamic result display
- Responsive design

---

## User Workflow

1. Open EduGenie.
2. Select a module.
3. Enter a topic or question.
4. Click Generate.
5. View the AI-generated response.

---

## Advantages

- Simple interface
- Responsive layout
- Easy navigation
- Interactive learning experience
