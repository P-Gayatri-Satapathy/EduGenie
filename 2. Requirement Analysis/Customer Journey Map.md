# Customer Journey Map

## User Persona
Student / Self-Learner

| Stage | User Action | Experience | EduGenie Solution |
|--------|-------------|------------|-------------------|
| Discover | Opens EduGenie | Curious | Simple and attractive interface |
| Explore | Selects a learning module | Easy navigation | Dropdown menu for task selection |
| Input | Enters a question or topic | Interactive | Text input area with clear instructions |
| Process | Clicks Generate | Fast response | FastAPI sends request to Gemini AI |
| Result | Receives AI-generated output | Satisfied | Accurate educational response |
| Learn | Studies the generated content | Improved understanding | Personalized explanations, quizzes, summaries, and learning paths |

## User Goals
- Learn concepts quickly
- Prepare for exams
- Save study time
- Improve knowledge through AI assistance
